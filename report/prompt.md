### [RELY]

- `kern/init/entry.S`：入口为 `kern_entry`，核心操作为 `la sp, bootstacktop` 和 `tail kern_init`。

- `kern/mm/mmu.h`：`PGSHIFT = 12`，每页 4096 字节。
- `kern_init`：清零 `edata` 到 `end`，调用 `cprintf`，无限循环，不返回。
- `cprintf` → `vcprintf` → `vprintfmt` → 字符回调 → `cons_putc` → SBI。
- 平台为已有 Ubuntu WSL2、RISC-V GCC；使用 QEMU `virt` 和默认 OpenSBI。
- 课程包含入口解释、GDB 从复位到内核入口两个练习，报告需分析原理对应和未覆盖内容。
