# 操作系统实验

本仓库用于提交操作系统课程的小组实验。

## 分支与目录规范

- 每次实验使用一个独立分支，分支名为 `labx`，例如 `lab1`。
- 每个实验分支包含 `code` 和 `report` 两个目录。
- `code` 目录存放实验代码。
- `report` 目录包含：
  - `report.md`：实验报告；
  - `prompt.md`：本次实验使用的全部提示词；
  - `images`：实验报告中引用的测试截图。

实验分支的目录结构如下：

```text
code/
report/
├── report.md
├── prompt.md
└── images/
```
